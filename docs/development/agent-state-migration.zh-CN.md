# 私有状态迁移（历史说明）

本文曾配套 v0.10.0 的一次性私有状态迁移脚本，适用于当时从按 Agent 分目录的旧状态布局
切换到 `$HOME/.agentic_gpt/state/`。它不是当前部署或配置接口；当前仓库已移除该脚本，Agent
启动时也不会扫描、合并或自动转换旧状态。

维护旧版部署时，请使用与该部署完全匹配的版本化源码及
[v0.10.0 发布说明](../release-notes-v0.10.0.md)，并在任何转换前停止使用同一 `HOME` 的所有
Agent、备份配置与数据库 sidecar。不要从当前分支复制历史迁移命令，也不要让新实例直接覆盖
未核验的旧状态目录。
