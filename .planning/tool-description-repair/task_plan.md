# 工具描述修复计划

## 目标
依据 `docs/documentation-standard.md` 修复全部项目拥有的面向模型工具及参数描述；保持工具名称、输入结构、执行与授权行为不变。

## 阶段
1. 盘点定义、导出、实现边界及验证入口（完成）。
2. 按互不重叠的定义文件修复，核实输入、输出、错误与副作用（进行中）。
3. 验证实际工具导出及真实调用，同步受影响参考文档（待开始）。

## 约束
- 描述使用简体中文，保留 API 标识符。
- 不重写外部 MCP 服务返回的描述，不修改归档正文。
- 注解如有修复，必须有运行时行为依据，不把注解当作权限保证。
- 每阶段提交；仅提交本任务文件。
- 所有工作者不运行 build/lint/test/formatter，由父任务最后统一验证。
