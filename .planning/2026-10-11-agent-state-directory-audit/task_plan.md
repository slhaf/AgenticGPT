# Agent 状态目录来源排查

## 目标
确认 config.json 身份之外，当前代码哪些入口会在用户 state/agent 下创建目录。

## 阶段
### 阶段 1：源码与测试入口调查
- 使用 CodeGraph 追踪私有状态路径，独立核对测试 HOME 隔离。
- Status: complete
### 阶段 2：只读核对本机目录并交付
- 只读汇总目录名、文件类型与身份对应关系，区分已证实和推断。
- Status: complete
### 阶段 3：更新隔离规范
- 修改 AGENTS.md，要求 smoke 和新增测试使用临时 HOME，并在结束时清理。
- Status: complete
### 阶段 4：共享 state 根的重构影响分析
- 分析目录迁移、数据库身份、并发、恢复、接口投影、测试与文档影响。
- Status: complete
### 阶段 5：按已确认边界核对源码可行性
- 本体仅新布局、独立脚本运行时迁移、本地无 agentId 归属、远程身份保持原样。
- 核对转换所需格式与远程契约边界，记录偏差与可行性。
- Status: complete

## 约束
本轮只修改规范与分析记录，不实施状态布局重构、不运行测试、不删除用户状态、不读取秘密；每阶段提交。
