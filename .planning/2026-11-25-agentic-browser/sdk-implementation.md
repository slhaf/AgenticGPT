# 浏览器 SDK 实施

以 Browser 26.1111.21308 的公开契约和已确认的去留范围为准。本轮沿用 Agentic 的租约和 MCP 工具，手册另行处理。

| 阶段 | 可交付结果 |
| --- | --- |
| 1 | REPL 跨调用保留绑定，截图返回 JPEG 字节，图片通过 MCP 原生内容传回。 |
| 2 | 标签归属、用户页接管、交付和交接、后台批量读取及释放清理。 |
| 3 | 对齐可访问性树、坐标和 DOM 操作、剪贴板、Playwright 页面与定位器。 |
| 4 | 接入视口、窗口与标签管理、页面资源、网页公开的 WebMCP 能力。 |
| 5 | 在远端通过真实 Agentic、Chromium 和打包扩展验证，回收可安装的构建产物。 |

各阶段分别提交。实际验证以跨调用状态、标签所有权、操作副作用和图片内容为准。

## 0.4.0 实施结果

扩展仓库完成八次分阶段提交，最终提交为 `245fda3`。Agentic 沿用现有 WebSocket 协议和 MCP 工具。模型手册留待下一阶段。

远端 Chromium 158 加载了生产扩展，并通过实际 Agentic 的 MCP 入口完成以下验证。

- 在真实 SDK 对象上核对了 111 个约定的公开方法，包括四种原生 JS 对话框。Playwright 定位、跨站嵌套 frame、并行输入、导航、严格 CSP 页面的只读异步求值均已实际执行。
- AX、坐标、可见 DOM 和剪贴板共 28 个方法通过输入场景。覆盖控件延迟更新、过期编号、网页复制按钮、跨源 iframe 的剪贴板策略和租约释放后的恢复。
- REPL 跨调用复用顶层声明及闭包。MCP 实际返回 JPEG 图片，裁剪图为 160 × 90，视口为 1100 × 637，整页为 1085 × 2647。
- 两个 Agentic 同时配对一个 profile 时，验证了互斥、同名任务的交接隔离、临时页清理和用户页保留。包含离页确认框的释放、空闲到期、断线、浏览器重启重连与重建 REPL 均已验证。
- 视口设定与还原、窗口与标签组整理、审计和页面资源清单均已通过。开启原生 WebMCP 的 Chromium 还验证了主文档与子框架注册的工具、同名替换及导航后旧句柄失效。

可安装的 ZIP 共 795711 字节，SHA-256 为 `a7fa2869c25c1f6dabb06397c5701325fad2407a1cf4082ef2bee41985ee63da`。ZIP 中 27 个文件均与加载测试的解包目录逐字节一致。
