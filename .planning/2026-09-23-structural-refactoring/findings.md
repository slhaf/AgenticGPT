# Structural refactoring findings

- Existing five-crate graph is Agent→Protocol+apply-patch, Hub→Protocol, browser-host independent; Console separate Gradle. No evidence currently justifies a new crate.
- Pre-fix `jobs::start_process_job_inner` stored admission Config while `run_async_job` reread `state.config` before policy/preflight/spawn. This discrepancy was subsequently reproduced deterministically (below) and repaired; it is no longer merely source-level inference.
- Current uncommitted diff before plan initialization affects only the unrelated earlier WP-R scoped findings file. Preserve it verbatim outside staging.
- CodeGraph targeted exploration confirms Agent stdio direct branch and HubCommand trampoline with shared gate, plus duplicated Hub Job projection helpers; preserve intentional ingress contracts.
- New worker implementation slices have disjoint ownership. Protocol retains root public facade; no wire version or serde contract changes. User authorizes design patterns/crate splits when justified, not as a mandate; present evidence favors private domain modules and narrow functions rather than another crate.
- Deterministic pre-fix reproduction in isolated detached worktree (`0b46d64` source plus one regression): `cargo test -p agentic-gpt --bin agentic-gpt admitted_process_keeps_policy_snapshot_across_reload -- --nocapture` ran one test and failed: actual `Rejected`, expected `Completed` (artifact://569). Current-thread test admits printf, updates live policy to deny before the spawned async worker runs. Initial invocation with `--exact` filtered the test (artifact://567); corrected invocation without it. Effective config boundary chosen: admission-time snapshot for Process/Skill, and batch preflight through queued worker. This fixes the proven mismatch while new admissions use new config.
- Current Agent route choice: Process Exec/Batch convert Hub wire payloads at `local_service` ingress and stdio typed arguments after one `operation::authorize`; shared `dispatch_process` owns group normalization, Job execution, terminal hook/source and slim projection. Other resource-specific branches stay independent. A private `dispatch_inner` exhaustiveness arm asserts the conversion invariant.
- Config lifetime choice: one `Arc<Config>` captured for Process/Skill Job admission, audit and asynchronous work; Process batch uses its preflight/confirmation snapshot for prepared admission and queued workers. `supervisor::StartupIdentity` remains separate from live-reload restart diagnostics because it watches a distinct startup launch resource set.
- Agent owner choice: `skills.rs` owns SkillLeaseManager and package digest (shared runner/installer lock identity and digest bytes); core Jobs no longer imports installation persistence for package metadata. `exec::normalize_roots` is shared only for configured root expansion/canonicalization/dedup; effect-specific process/file checks remain local, with typed expansion/resolution failures preserving prior observable messages.
- Hub owner choice: `state::projection` owns neutral Job cache/live projection and HubInfo; routes and Apps MCP retain distinct edge auth/error shapes. Apps call/descriptor membership is generated router ∩ explicit profile allowlist, with annotation metadata independent. Room/Agent lease and run owners unchanged.
- Protocol choice: seven private wire-domain modules with crate-root reexports, same public names/serde definitions, no extra crate or universal command identity. Rust full workspace 668 passing tests and live Agent/Hub parity gate passed after cutover (artifact://617, artifact://643).
- Android choice: Room is fact authority; one local transition owner coordinates UI, receiver, boot and Activity. Overdue pending rows use due-bound atomic claim before notification; scheduler snooze accepts full item. Hard scheduling failure CAS-marks only the matching pending revision, overdue sentinel triggers instead of failing, ExactRequired does not inexact-fallback, and ExactPreferred persists a visible/actionable `Degraded` status recoverable after exact success. Shared JVM policy tests passed after final source (artifact://694); focused independent review found no remaining patch-introduced issue. Android SDK/device unavailable, so Android app compile, Room/OS and visual/device behavior remain unproven (artifact://620, artifact://640).
- Release choice: tag-only workflow preflight gates packaging/publication at same SHA and checks exact Agent/Hub Cargo versions; local `v0.0.0` mismatch rejected, `v0.9.1` preflight plus live parity passed with a reachable PyPI mirror (artifact://643). Strict Clippy is existing separate CI debt, not concealed as release gate; hosted GitHub/ARM/external importer not exercised.
