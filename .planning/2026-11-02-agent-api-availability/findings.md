# 调查记录

- 邮件与密钥工具发现仅按工具集开关过滤；配置加载却按开启状态要求配置完整，导致 MCP 客户端无法提前发现 API。
- CLI 工具集开关能写入不完整配置，但之后无法读取或关闭；配置界面和通用配置更新则拒绝保存。移除配置加载与保存中的完整性门槛后，同一开关可正常读取及关闭。
- 邮件后台要在配置完整时才发起同步；密钥 API 要在创建 owner 与同步前判断缺项。已填写内容的格式仍在配置入口校验。
- HTTP MCP 是带认证的独立网络入口；令牌不可用时不能开放监听。
- 现有真实 Unix MCP 测试没有覆盖开启不完整的邮件和密钥工具集。补充一条真实进程链路可长期保护客户端发现、调用错误、工具集关闭与热更新，不属于固定文案或直接映射测试。
