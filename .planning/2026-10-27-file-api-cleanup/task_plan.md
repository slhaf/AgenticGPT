# File API 清理与缺陷修复

## 目标与范围

按已审查并获准的八组问题，清理 `file.search/edit` 及共用授权代码，再修复替换／移动失败后的临时文件残留。每阶段完成验证后创建 Conventional Commit。

保留临时文件创建重试、确认前后身份复核、既有路径重复解析、图片预算估算与 8 MiB 检查位置。公开请求、响应、权限、资源上限与审计字段保持一致。

## 阶段

1. **已完成：行为不变的清理。** 搜索单次解析；结构化搜索结果与扫描计数；直接传入授权路径；先检查结果上限；删除无消费者 diff；合并路径集合；删除重复状态写入；结构化写入结果与审计消费。远端 workspace 测试与严格 lint 通过。
2. **已完成：临时文件清理缺陷。** 重命名失败后保持临时文件可清理；真实文件系统回归测试已先在旧实现复现，再验证修复。远端 workspace 测试与严格 lint 通过。

## 验证与完成标准

- 构建、测试、Clippy 均通过现有 `~/.local/bin/remote-build`，不改构建助手。
- 第一阶段复用现有契约、搜索、批次、编辑与审计测试；不为机械重构新增断言。
- 第二阶段新增第五档测试：真实暂存文件、真实重命名失败与清理副作用，保证源／目标不被改变且无临时文件残留；既有测试没有覆盖该失败模式。
- 修改后检查实际消费者，按需更新文档。内部重排不强制修改公开参考。
- 每阶段分别提交，仅包含本任务文件。
