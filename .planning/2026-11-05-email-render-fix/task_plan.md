# 邮件 HTML 图片渲染修复

## 目标

直接将邮件原始 HTML 和所需资源渲染为图片，解决图片裁切和复杂邮件排版问题，不针对单封邮件特殊处理。`imageWithRemote` 的现有区分不是选型硬约束。新增防护措施必须向用户说明。
