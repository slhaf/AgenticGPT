# Config TUI 输入修复

## 目标
按实际字段语义修复前置表单和 Review 的枚举、数字、集合、凭据引用输入；补齐格式帮助及错误定位。配置文件合同与域校验保持现有语义。

## 阶段
1. [complete] 统一字段输入元数据、修复邮件类型错误定位。
2. [in_progress] 接入枚举/数字与引用/Host白名单结构化编辑器，补齐帮助、文档及交互回归。
3. [pending] 远程测试与真实终端验证，独立审查收尾。

## 测试保留价值
新增测试限于第④档：真实 ConfigTuiApp 键盘事件经过编辑器、暂存配置和验证，观察配置结果与取消行为。保护枚举不能通过文本输入破坏、Host 白名单三种模式不混淆、引用来源切换和取消不意外写入；现有 app tests 不覆盖这些链路。不添加元数据列表或文字断言。

## 执行边界
所有 Rust 构建/测试使用既有 remote-build；不读取真实用户 Agentic 状态。每阶段 Conventional Commit。子agent只编辑分配文件，不提交。
